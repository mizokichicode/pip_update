# pip-update

Pythonパッケージの一括更新ツール

## 機能

実行環境にインストールされているPython用のパッケージを一括更新します。
パッケージの一括更新は、次のPythonバージョンが対象です。

* Ver.3.15.x (2031.10まで)
* Ver.3.14.x (2030.10まで)
* Ver.3.13.x (2029.10まで)
* Ver.3.12.x (2028.10まで)
* Ver.3.11.x (2027.10まで)

## 使用環境

* macOS 27/26
* Windows 11

## 使用方法

### macOS

```
> git clonse https://github.com/mizokichicode/pip_update.git
> cd pip-update
> python3 main.py
```

### Windows

```
> git clonse https://github.com/mizokichicode/pip_update.git
> cd pip-update
> py main.py
```
